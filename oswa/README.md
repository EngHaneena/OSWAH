# منصة أسوة (Oswa)

**مشروع مشارك في [تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي](https://islamicaich.org/)**

تعرض المنصة مواقف من سيرة النبي ﷺ بناءً على مشاكل وتحديات يكتبها المستخدم، مع صياغة مقدمة تعاطف واستخلاص عبر وخطوات عملية باستخدام الذكاء الاصطناعي، مع ضمان **عدم توليد النصوص الشرعية** والمحافظة على المرجعية الموثوقة.

---

## ✨ التحديثات الجديدة (النسخة المحدثة)

1. **الشريط العلوي الموحد (TopNav):**
   - شريط ثابت (Sticky) مع تأثير زجاجي (Backdrop blur) وتصغير لطيف عند التمرير.
   - تبويبات رئيسية معرفة برمجياً في `config/nav.ts` (الرئيسية · عظة وعبرة · ركن الأطفال · التصميم في بيئة التطوير).
   - زر تبديل اللغة الفوري بين العربية والإنجليزية (AR / EN) مع ضبط الاتجاه (RTL / LTR) ديناميكياً.
   - زر الوضع الداكن بثلاث حالات (فاتح / داكن / تلقائي حسب النظام) بدون وميض وبدعم كامل للمتغيرات التصميمية (Design Tokens).
   - خانة المستخدم الذكية: دعم غير المسجل، الضيف (Guest) مع حفظ محلي، والمستخدم المسجل بدائرة الحساب والقائمة المنسدلة.
   - درج جانبي متجاوب للجوال (Mobile Drawer) يراعي إمكانية الوصول الكاملة ومناطق الأمان (Safe Area Insets).

2. **حساب المستخدم والخصوصية المتقدمة (`/account`):**
   - صفحة ملف شخصي تتيح تعديل الاسم المعروض (حتى 40 حرفاً)، والجنس (اختياري)، والعمر (اختياري بين 3 و120 سنة).
   - إشعار خصوصية صريح: البيانات لا تُرسل للنماذج اللغوية، ولا تدخل في محركات الاسترجاع، ولا يُستنتج منها أي ميول دينية.
   - اقتراح ركن الأطفال لمن هم دون سن 13 عاماً بأسلوب تشجيعي لطيف دون حظر أي قسم.
   - زر تصدير البيانات الكاملة بصيغة JSON.
   - زر حذف الحساب وبياناته نهائياً مع نافذة تأكيد صريحة وسياسات RLS متوافقة مع قاعدة بيانات Supabase (`profiles`).
   - صفحة سياسة الخصوصية المحدثة (`/privacy`) باللغتين.

3. **التذييل المعتمد (SiteFooter):**
   - شريط سفلي متناسق يحمل اسم التحدي الرسمي كرابط خارجي إلى `https://islamicaich.org/`.
   - أيقونة LinkedIn الرسمية تقود إلى صفحة الفريق `/team`.
   - سطر شفافية الذكاء الاصطناعي وروابط الخصوصية والتفاصيل.

4. **صفحة الفريق على طريقة لينك تري (`/team`):**
   - صفحة مركزية أنيقة تدار بالكامل من ملف واحد `config/team.ts`.
   - بطاقة بارزة لقائدة الفريق، متبوعة ببطاقات بقية الأعضاء وروابط LinkedIn وGitHub للأعضاء الذين يملكونها، دون عرض أي بريد إلكتروني.

5. **الزخارف والهوية البصرية الإسلامية (BackgroundOrnaments):**
   - طبقة زخرفية إسلامية في الخلفية بشفافية هادئة (6–8%) لا تعيق القراءة وتراعي معايير التباين AA.
   - نجمة ثمانية وزخارف أرابيسك ناعمة في الزوايا.
   - دعم كامل لتعطيل الحركة عند تفعيل تفضيل تقليل الحركة (`prefers-reduced-motion`).
   - الالتزام التام بالضوابط الشرعية: لا تصوير ولا تجسيد للنبي ﷺ، واعتماد النور المشرق فقط (`ProphetGlow`).

6. **المربعات العائمة التفاعلية (Floating Tiles):**
   - مربعات عائمة على جانبي الشاشة في الحواسيب المكتبية بمواضع وميول محسوبة لا تعيق العنوان أو المحتوى الرئيسي.
   - حركة عوم بطيئة وتوقف سلس عند المرور بالمؤشر (Hover Pause).
   - تحول تلقائي في شاشات الجوال والتابلت إلى شريط أفقي قابل للتمرير (Scroll-snap).
   - نافذة تفصيلية (Modal) عند النقر مع عرض النصوص الشرعية والمصادر ودرجة الحديث بالعربية فقط حتى في الواجهة الإنجليزية.
   - زر إخفاء/إظهار المربعات العائمة لمحبي الواجهات الهادئة مع حفظ التفضيل محلياً.

## المبادئ الأساسية للمنصة
1. **الموثوقية أولاً**: النصوص الشرعية (الأحاديث والآيات) تأتي من قاعدة بيانات المنصة (Supabase) ولا يولدها النموذج اللغوي (LLM) أبدًا.
2. **الاحترام والتقديس**: لا يتم تصوير النبي ﷺ بأي شكل بشري أو تجسيد جسدي، ويُرمز له بنور مشرق (Glow) ذهبي أبيض فقط، والصحابة الكرام يتم تمثيلهم من الخلف فقط.
3. **سلامة وخصوصية المستخدم**: فحص تلقائي للأزمات، عدم استنتاج أي ميول دينية، وعزل بيانات الملف الشخصي تماماً عن طلبات الذكاء الاصطناعي.

## المتطلبات التقنية
- Node.js >= 20
- npm >= 10
- حساب Supabase (Auth + Postgres + pgvector)
- حساب Anthropic (مفتاح API اختياري للذكاء الاصطناعي)

---

## التشغيل محلياً

1. تثبيت الحزم:
```bash
npm install
```

2. إعداد المتغيرات في `.env.local`:
```bash
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
ANTHROPIC_API_KEY=your_anthropic_key
LLM_MODEL=claude-3-5-sonnet-20241022
```

3. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على [http://localhost:3000](http://localhost:3000).

4. تشغيل الاختبارات الآلية (Vitest):
```bash
npm test
```
