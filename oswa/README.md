# منصة أسوة (Oswa)

**نموذج أولي (MVP) لمنصة «أسوة»، تم بناؤها ضمن تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي.**

تعرض المنصة مواقف من سيرة النبي ﷺ بناءً على مشاكل وتحديات يكتبها المستخدم، مع صياغة مقدمة تعاطف واستخلاص عبر وخطوات عملية باستخدام الذكاء الاصطناعي، مع ضمان **عدم توليد النصوص الشرعية** والمحافظة على المرجعية الموثوقة.

## المبادئ الأساسية للمنصة
1. **الموثوقية أولاً**: النصوص الشرعية (الأحاديث والآيات) تأتي من قاعدة بيانات المنصة (Supabase) ولا يولدها النموذج اللغوي (LLM) أبدًا.
2. **الاحترام والتقديس**: لا يتم تصوير النبي ﷺ بأي شكل بشري أو تجسيد جسدي، ويُرمز له بنور مشرق (Glow) ذهبي أبيض فقط، والصحابة الكرام يتم تمثيلهم من الخلف فقط.
3. **سلامة المستخدم**: المنصة مزودة بفحص تلقائي للمحتوى لمعالجة الأزمات (مثل إيذاء النفس) بتقديم خطوط الدعم، ولا تقدم المنصة فتاوى شرعية للأحكام الشخصية.

## المتطلبات التقنية
- Node.js >= 18
- حساب Supabase (Auth + Postgres + pgvector)
- حساب Anthropic (للحصول على مفتاح الـ API)

## إعداد المشروع محلياً

1. استنساخ المستودع وتثبيت الحزم:
```bash
npm install
```

2. نسخ ملف الإعدادات وإضافة المفاتيح:
```bash
cp .env.example .env.local
```

3. تجهيز قاعدة البيانات (Supabase):
   - قم بإنشاء مشروع جديد في Supabase.
   - افتح SQL Editor وقم بتشغيل محتويات `supabase/migrations/001_initial.sql` لإنشاء الجداول وإعداد pgvector.
   - (اختياري للتجربة) قم بتشغيل `supabase/migrations/002_demo_data.sql` لإدخال بعض البيانات التجريبية.

4. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح الرابط `http://localhost:3000` في المتصفح.

## الهيكل التقني
- **Next.js (App Router)**: الواجهة الأمامية والمسارات (Routes).
- **Tailwind CSS**: التنسيق والهوية البصرية.
- **Supabase**: إدارة قواعد البيانات والمصادقة.
- **@xenova/transformers**: إنشاء متجهات نصية (Embeddings) للمواقف محلياً في الخادم لدعم البحث الدلالي.
- **Anthropic API**: لتلخيص العبرة واستخراج الخطوات العملية بأسلوب متعاطف.

## ملاحظات وموجهات هامة
- **البيانات التجريبية**: تم إضافة مواقف وسجلات بكلمة "تجريبي". يجب استبدال جميع هذه البيانات بمواقف موثقة قبل إطلاق النسخة النهائية.
- **أرقام الطوارئ**: تم توفير أرقام طوارئ تجريبية في `config/emergency.ts` ويجب تحديثها للجهات الرسمية قبل الإطلاق.
- **الرسوميات (SVG)**: جميع الرسوم في المنصة تم توليدها برمجياً لضمان الامتثال لضوابط التصوير، ويمكن التحكم بطريقة عرض الصحابة عبر إعداد `COMPANION_RENDER_MODE`.
